# Mado Studio 使用指南

首次使用见 [快速开始](../README.md#快速开始)。以下操作在 Mado Studio 中完成。

## 编辑布局

- 从左侧组件库点击卡片可添加到空位，也可以拖到指定位置。拖动已放置的卡片可以移动位置；放到另一张卡片上时，如果两张卡片都能放下，会交换位置。聚焦卡片后也可用方向键移动。
- 点击预览中的卡片，可以设置规格、标记色、数值动画或状态提醒。点击空白处或按 Esc 回到「屏幕配色」。试播结束后，预览恢复显示实时读数。
- 点击卡片右上角的「×」从布局草稿移除。使用「撤销改动」可撤销最近一次卡片或页面修改。
- 预览可用 1–5 个页面。点加号新增，点击当前页签的名称可改名，拖动页签可调整顺序。至少有两页时，可设置自动轮播间隔为 5、10、15、30 或 60 秒。
- 点击「应用布局」保存全部页面和屏幕配色，桌面控件和已连接的实体屏会使用新配置。窗口顶部的「主题」用于切换 Studio 自身的外观，即时保存。

## 桌面控件

点击窗口顶部的「桌面控件」即可打开。控件默认置顶，可以拖到需要的位置。移入鼠标或聚焦后会出现工具栏，可以返回布局编辑器、切换置顶或关闭控件。置顶偏好会保存在本机。

可以点击底部页名、工具栏箭头，或聚焦后按左右方向键来切页。控件里的播放／暂停开关只影响当前窗口，若未在布局中设置间隔，手动播放使用 10 秒。操作控件时轮播暂停，离开后继续。

关闭编辑器后，控件和采集会继续运行。可以从控件的「编辑布局」或 macOS Dock 返回 Studio。退出 App 会关闭所有窗口并停止采集。重新打开 App 后可恢复已应用的页面、轮播、配色和置顶偏好。

## 连接 Codex

1. 安装 [Codex CLI](https://developers.openai.com/codex/cli)，然后点击 Studio 里 Codex 分组旁的采集状态，打开设置。
2. 点击「连接 Codex」。Studio 会查找本机 CLI；如需指定位置，可展开「CLI 路径」并填写可执行文件的绝对路径。
3. 如果需要登录，点「浏览器登录」，按 OpenAI 页面提示完成 ChatGPT 登录。也可先在终端运行 `codex login`，再回 Studio 点「重新检测」。
4. 连接成功后，设置会显示实际返回的额度窗口和速度样本。把所需卡片加入布局，再点击「应用布局」。

额度卡和恢复倒计时跟随剩余比例最低的额度窗口。任务状态优先显示最近开始且仍在运行的本机 Codex 对话。「暂停采集」会清空读数，并保存停用设置。

## 添加自定义采集器

1. 打开「管理采集器」→「新建采集器」，选择快速开始、HTTP 接口或本地文件模板。
2. 在入口脚本的 `defineModule()` 中编写采集配置和逻辑。需要其他文件时，可在项目文件树中添加。
3. 点击「测试运行」，查看卡片预览、输出和日志。可在「样例数据」提供离线响应。需要读取实际资源时，使用「用实际资源试跑」并确认授权。
4. 试跑通过后点击「发布」，确认所需授权，然后回到布局添加卡片。后续脚本修改先保存为草稿，再次发布后生效。

可以导出已发布的模块，也可以导入信任的模块作为草稿。清单、脚本 API 和完整示例见[采集器 SDK](display-config-model.md#sdk)。

## 连接实体屏

用 USB 数据线连接 **LILYGO T-Display-C5 V1.0**。打开 Studio 预览底栏的设备状态，点「烧录固件」，选择自行下载的 [Mado ZIP 烧录包](firmware-resources.md#studio-烧录包)和 USB 串口，再点「开始烧录」。烧录完成后返回连接面板。

- **USB**：用数据线连接设备和电脑，选择串口并点「连接设备」。
- **蓝牙（macOS）**：长按设备 BOOT 进入设置，短按用户键选中「蓝牙配对」，短按 BOOT 开启配对。Studio 选择「蓝牙」，扫描后连接 Mado，在系统提示中输入设备屏上的六位码。长按 BOOT 返回仪表盘。配对窗口持续两分钟；之后已配对的 Mac 可直接扫描并连接。要清除绑定，在设备配对页选择「忘记电脑」并确认。
- **Wi-Fi（预览）**：先通过 USB 或已配对的蓝牙连接，点「配置 Wi-Fi」，输入网络名称和密码后点「配置并连接」。以后可在「Wi-Fi」中扫描。若发现失败，在设备上长按 BOOT 进入设置，从「Wi-Fi」页查看 IP 并填入 Studio。该页也可选择「忘记网络」。当前支持个人 WPA2、WPA3 和开放网络，真实局域网下的 DHCP、发现和同步仍待[实板验证](firmware-resources.md#实板验收)。

设备的用户键可以切页。断线后，设备保留最近画面，Studio 会尝试重连。预览底栏的推送间隔在下次连接时生效，蓝牙连接两次推送之间至少间隔两秒。实体屏的亮度和方向可在预览中调整，取决于固件提供的控制项。

## 源码开发

从项目根目录运行：

```sh
npm test
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
```

macOS 可运行 `npm run tauri build -- --bundles app`，在 `src-tauri/target/release/bundle/macos/` 生成 App 包。

运行 `npm run dev` 后，可以打开 `http://localhost:1420/tests/fixtures/display.html` 查看布局、数值边界、滚动和提醒样例，或打开 `http://localhost:1420/tests/fixtures/appearance.html` 查看外观组件样例。实现细节见[总体设计](design.md)、[显示协议](display-protocol.md)和[屏幕 UI 规范](display-ui.md)。
