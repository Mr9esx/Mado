# 桌面控件

将虚拟屏变为 App 的本机显示输出，不依赖硬件连接。

- 主窗口入口命名为「桌面控件」，布局提交命名为「应用布局」。
- 控件沿用 320 × 170 画布、已应用布局和本机采集数据。首次打开即显示默认布局，不等待硬件同步。
- 控件为独立无边框窗口，可拖动。悬停或键盘聚焦显示「编辑布局」「置顶/取消置顶」「关闭」操作。
- 默认置顶。置顶偏好存入 App 配置目录的 desktop-widget.json，重新打开或重启后仍有效。调用原生窗口置顶接口，失败时显示错误，不伪造成功状态。
- 关闭编辑器不会停止仍打开的控件或采集。控件可重新打开编辑器；macOS Dock 再次打开 App 时恢复编辑器。
- 控件关闭后可再次打开，显式退出 App 会退出所有窗口和采集进程。
- 编辑器预览与桌面控件状态栏标识本机和真实 App 版本，不显示模拟硬件连接、供电或固件版本。
- 仅改变本机展示输出；设备画布的默认设备模式仍保留，供硬件开发和原型核对。
- 本次不增加开机自启、跨屏位置持久化、控件缩放或独立硬件传输协议。

采用现有共享快照，而不复制一套采集器/布局状态，保证两个窗口的数据一致。保持内部窗口 label 为 display，以兼容现有权限与窗口事件。

验证：置顶偏好默认值/持久化/写入失败；本机画布无硬件状态；原有布局与采集回归；真实 App 置顶切换、关闭并重开控件、关闭主窗口后继续显示和返回编辑器。
