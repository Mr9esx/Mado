# Studio 控件与主题统一

用户最终确认 App 与桌面控件主题分开设置。

问题：仅部分 Button/Input 使用 ReUI；多页管理采用原生 select 和局部按钮；透明材质、局部硬编码颜色与画布字体混用于 App；主题没有配置入口。

- App 的 Button、Input、Select、Tabs、Dialog 使用 ReUI v1 官方源码，保留出处与许可证。设备画布的像素卡片继续按 display-ui.md 渲染。
- App 使用系统无衬线字体；设备画布与代码使用 Maple Mono。统一语义颜色、6 px 控件圆角、32 px 小控件高度、8/16/24 px 间距。去掉噪点和漂浮的透明控件层。
- 编辑器、设置、采集器共用浅色/深色 token。默认跟随系统。独立设置桌面控件深色/浅色，默认深色；库缩略图、编辑预览、采集器预览与实际控件同步。
- 设置包含「外观」和「数据源」标签；原 Codex 连接设置复用原有行为，数据源徽章直接进入数据源标签。
- Rust 管理外观偏好并原子持久化，变更以事件通知全部窗口；启动、新建窗口和系统外观变化均正确恢复。保存失败保留旧配置并显示错误。
- 保持现有已应用页面、轮播、采集器和置顶偏好，外观变更无需重新应用布局。
