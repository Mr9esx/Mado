# Mado Wi-Fi 连接

Studio 通过已连接的蓝牙或 USB 给设备配置 Wi-Fi。首次配网在 Studio 输入网络名和密码。设备成功取得 IPv4 地址后才保存新网络，失败时恢复之前保存的配置。设备端「Wi-Fi」页显示 IP，支持确认后忘记网络。

Studio 经当前连接下发每次配网生成的 TLS 服务端证书、私钥和专用 CA。Studio 保存客户端证书、客户端私钥和 CA。Wi-Fi 使用双向 TLS，mDNS 只发现地址，连接后再校验设备 ID。现有 USB、BLE 和 Wi-Fi 共用显示会话，每块屏同时由一个连接控制。

Studio 配网成功后切换到 Wi-Fi。再次连接可扫描或手动填写 IP，已连接时随设备重启或 IP 变化重新连接。首版支持常规局域网、开放网络和 WPA2/WPA3 个人网络。
