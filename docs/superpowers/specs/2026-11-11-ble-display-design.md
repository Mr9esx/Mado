# Mado BLE 显示连接

长按设备 BOOT 进入设置，选择「蓝牙配对」。设备显示六位临时码，用户在 Studio 选择附近的 Mado，并在系统提示中输入码。配对窗口结束后只接受已有绑定。保留设备端清除绑定入口，方便更换电脑。

BLE 与 USB 使用同一显示协议。BLE 将换行分帧的字节流拆成 GATT 写入和通知，完整帧通过原有校验后才可提交。BLE 端要求经过验证的加密和绑定。固件将会话绑定到具体通道，断开 BLE 立即释放会话，保留最后画面。Studio 同一时刻控制一个实体屏。

本阶段验收 BLE 发现、配对、复连、页面设置和完整快照。推送速度以实板测量为准。Wi-Fi 配网和局域网传输属于下一阶段。
