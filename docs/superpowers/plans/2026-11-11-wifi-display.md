# Wi-Fi 显示连接实现计划

依据 [Wi-Fi 设计](../specs/2026-11-11-wifi-display-design.md)，以已实机验证的 BLE 和 USB 为配网通道。

1. 在固件网络任务验证 SSID 和密码、候选网络和旧网络切换、DHCP 后保存、忘记网络和重连。设备菜单提供 IP 和清除操作。
2. 使用 mDNS 发布设备 ID，并通过双向 TLS 提供与 USB、BLE 相同的显示协议。对断线、换网和半包重置连接状态。
3. Rust 实现证书生成与保存、配网请求和轮询、局域网发现及手动地址。接入原显示线程，连接前校验证书和握手设备 ID。
4. Studio 增加 Wi-Fi 配网、已配对设备列表与连接状态，验证前端、Rust、固件及开发板。
