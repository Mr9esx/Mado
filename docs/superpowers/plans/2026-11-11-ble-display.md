# BLE 显示连接实现计划

依据 [BLE 显示连接设计](../specs/2026-11-11-ble-display-design.md)，先连接 ESP32-C5 和 macOS Studio。

1. 为字节流添加固件主机用例，验证跨分片、断线重置和超长帧恢复。抽出 USB 和 BLE 共用的分帧器，并按输入通道绑定协议会话。
2. 用 ESP-IDF NimBLE 增加 GATT 服务，接收带响应的分片写入并通知返回帧。固件主循环处理完整消息，使用 NVS 保存蓝牙绑定。在现有按键菜单加入配对和忘记电脑操作。
3. Rust 使用 btleplug 发现匹配服务的设备并实现读写适配器。复用现有同步线程和设备状态，Studio 的设备面板提供 USB / 蓝牙选择、扫描、连接和断开。
4. 运行前端和 Rust 测试、固件主机测试及 ESP32-C5 构建。实板验证 USB 回归、系统配对、断线与重连；记录可以复验的结果。
